# Introduction to Databases Course Repository

This repository contains coursework, lecture notes, practical SQL scripts, and reference materials for learning relational database management systems. 

## Directory Guide

### `notes/`
Contains core conceptual overviews covering database design, relational algebra, the entity-relationship model, normalization forms (1NF, 2NF, 3NF), and basic indexing principles.

### `homework/`
Holds practical SQL files and lab assignments. For example, `homework_1.sql` covers database creation, primary and foreign key constraints, data population, and query filtering using clauses like `WHERE`, `JOIN`, and `ORDER BY`.

### `articles/`
added readings, design patterns, and cheat sheets for writing efficient and readable SQL code.
